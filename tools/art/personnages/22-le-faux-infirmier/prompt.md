## Étape 1 — le personnage

Pièces jointes, dans cet ordre :

1. le résultat de l'étape 1 du dossier `21-gontran-lameche` (`resultat.png`, à générer d'abord)
2. `2-visage.png` — lunettes / masque

Prompt (format **3:4**) :

```
Same art style, outlines and shading as the attached images. Image 1 shows a character. Redraw EXACTLY the same character (same face, expression, hair, body shape, proportions, clothes and colours) with one change: he is now disguised as a nurse: a long white nurse coat replaces the red suit jacket, and he wears the black eye mask from image 2; he KEEPS the same top hat, orange trousers, moustache and closed umbrella. Full body, three-quarter view, body turned slightly to the right, same scale and same art style, plain white background, no ground shadow, no text, no other character, no object other than those mentioned.
```

Garde l'image réussie sous le nom `resultat.png` dans ce dossier.
