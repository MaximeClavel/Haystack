# Actions de la foule

**Dans le jeu** : Les habitants de base dans les 6 poses les plus fréquentes de la foule. Pour chaque planche `planche-*.jpg`, une génération par action (36 en tout ; commence par marche et assis).

Joins une seule planche par génération. Nom du résultat : par exemple `planche-2-marche.png`.

**Pièce jointe** : une planche `planche-*.jpg` de ce dossier.

## 1. marche  — format **16:9**

```
Here is a character sheet of six townspeople. Redraw exactly the same six characters, same faces, hairstyles, body shapes, skin tones and clothes, with the top still bright saturated green and the bottom still bright saturated blue, in the same order from left to right, now walking to the right, mid-stride, arms swinging naturally. All facing right in three-quarter view, full body, same scale and same art style, plain white background, lots of empty space so they never touch, no text, no extra objects.
```

Résultat à enregistrer ici sous le nom `planche-N-marche.png`.
