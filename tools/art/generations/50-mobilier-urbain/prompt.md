# Mobilier urbain

**Dans le jeu** : Bancs, lampadaires, poubelles, boîtes aux lettres, bornes, cabines, abribus, panneaux, cônes, barrières, plaques d'égout.

**Pièce jointe** (à chaque génération) : `ref-diorama.jpg` (référence de style et d'angle pour la ville)

## 1. mobilier-1  — format **16:9**

```
Same art style, outlines, colour palette and soft painted shading as the attached reference image: a lush, cozy French small town, hand-painted anime mobile-game look, warm daylight from the upper left. Isometric view from a high three-quarter angle, exactly the same camera angle as the reference. Separate objects side by side, same scale, generous empty space between them so they never touch or overlap. A wooden park bench, the same bench broken in the middle, an old cast-iron street lamp, a green public litter bin, a yellow French letter box on a post, a red fire hydrant, an orange traffic cone. Plain white background, no ground under the objects, no cast shadow, no text, no letters or numbers anywhere (leave every sign board blank).
```
