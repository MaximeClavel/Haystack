2. `01-personnages/04-ernest-lafouine/resultat.png` (son modèle : à générer d'abord)

C'est un **sosie** de « Ernest Lafouine, le voleur » : seul le détail décrit doit changer, c'est ce que le joueur doit repérer.

## Prompt — format **1:1**

```
Same art style, proportions, outlines and soft painted shading as the attached character sheet. Image 2 shows a character. Draw a mime who looks exactly like the thief (same tall slim body, same face, short brown hair, same orange knitted beanie, same black-and-white striped sweater, black trousers) but with NO mask at all. Everything not mentioned stays identical to image 2. Draw this ONE character twice on the same image, side by side, same scale: once in three-quarter front view and once in three-quarter back view, standing, full body, natural colours. Plain white background, generous empty space, no ground shadow, no text.
```

Enregistre l'image réussie dans ce dossier sous le nom `resultat.png` : elle sera jointe aux sections de la carte où il apparaît.
